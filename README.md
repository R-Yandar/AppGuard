# AppGuard – Seguridad y Control

**AppGuard** es una aplicación desarrollada para apoyar la gestión y supervisión de servicios de seguridad, permitiendo administrar usuarios y centralizar diferentes procesos operativos.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Java
- JDBC
- MySQL
- Git y GitHub

## Módulos

El sistema contempla los siguientes módulos:

- Supervisión
- Clientes
- Horarios
- Novedades
- Reportes
- Botón de pánico
- Notificaciones
- Configuración

## Gestión de usuarios

El módulo de usuarios está conectado a una base de datos MySQL mediante un backend desarrollado en Java.

Actualmente permite realizar las operaciones CRUD:

- **Crear** usuarios.
- **Consultar** usuarios registrados.
- **Editar** información.
- **Activar o inactivar** usuarios.
- **Eliminar** usuarios.
- **Buscar y filtrar** usuarios.

La comunicación del sistema se realiza mediante:

**HTML → JavaScript → API Java → DAO → JDBC → MySQL**

## Estado del proyecto

AppGuard se encuentra en desarrollo. Actualmente cuenta con interfaz gráfica, conexión con MySQL y el módulo de gestión de usuarios funcional.

## Proyecto académico

Proyecto desarrollado como parte del proceso de formación en **Análisis y Desarrollo de Software (ADS)**.
